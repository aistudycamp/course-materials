01

Setup

Set up the tools and the shared database before you plan the app.

  • Open VS Code.
  • Open the AI Study Camp folder from Week 1.
  • Open a new VS Code terminal and start Claude Code there.
  • Keep the project inside that folder tree, not on Desktop or Downloads.
  • Create a free Supabase account and a project named ai-study-camp.
  • Open Supabase Setup and follow its Claude prompt. It creates supabase.md, saves the safe connection details, and connects the Supabase MCP.
  • Confirm that supabase.md exists in your AI Study Camp folder and that Claude can see the Supabase MCP.

If Claude Code is not installed, use the Claude Code setup guide. Do the Supabase setup before moving to Plan.

02

Plan

Start with the user, the problem, and the first version. Do not start with a blank codebase.

Tell Claude: I want to build a small to-do app. Ask me questions one at a time about the user, the main flow, the visual direction, and the data we need to save. Then write a short PRD and implementation plan. Do not write code until I approve the plan.
PRD template
03

Foundation

At this point, Supabase should already be set up. Claude can now create the app foundation and connect it to the course project.

Tell Claude: Create the app foundation from the plan. Use Next.js for the app and my AISC Supabase project for the database. Use the existing supabase.md and Supabase MCP. Before making changes, explain what you are about to create and ask me before anything destructive.

Supabase

Stores the app data and handles accounts.

Next.js

Provides the pages, components, and server routes.

VS Code

Shows the project files and the terminal.

Claude Code

Reads the project, edits files, runs checks, and explains the work.

04

Build

Work in small slices. After each slice, open the app in the browser and check the result.

Core flow

Add, edit, complete, and delete a task. Check that data survives a refresh.

Accounts

Add sign up, sign in, and sign out. Keep each user's tasks private.

Design

Choose the layout, type, colors, and details. Ask Claude for options, then choose.

Testing

Ask Claude to test each flow, inspect errors, and explain anything unclear.

Keep saying: Make one change, run the app, and show me how I can check it in the browser.
05

Publish

Commit your work, push it to GitHub, connect the repository to Vercel, and test the live URL.

  • Confirm the app works locally.
  • Ask Claude to commit and push the current version.
  • Connect the GitHub repository to Vercel.
  • Add the Supabase values to Vercel's environment variables.
  • Test sign in, task changes, refresh, and sign out on the live URL.
