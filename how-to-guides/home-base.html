How-To Guide

Home Base

One command that always opens Claude Code in the same folder, from anywhere.

Why One Folder

Claude Code works best from one folder you always start in, your home base. Everything you build lives below it, and Claude can find the CLAUDE.md files that carry your project context. Start from a random folder instead, and none of that context is there.

1

Set It Up

You already made your home folder in Week 1, the one with work, personal, and learning inside it. Open Claude Code from anywhere and paste this to wire the shortcut to it.

claude
Set up a shortcut so typing `claude` always starts a session in my home folder from Week 1, no matter where I am. If you're not sure which folder that is, ask me for its name or path before doing anything. Add a shell function named `claude` to my shell config: with no arguments it switches to that home folder and starts the real `claude` command there; with a folder name as an argument it opens that folder inside my home base instead. Call the real `claude` binary explicitly so the function doesn't call itself. Reload my shell config so it works right away, and tell me the exact path it's pointing at.

Claude finds your existing home folder and wires the shortcut to it. Typing claude now always starts there.

Tip

If it asks to reload your terminal, say yes. If it doesn't ask, close and reopen your terminal once.

2

Use It

From any folder, on any day, type:

claude
claude Started in ~/alex-home

Working on something specific? Pass the folder name and Claude opens that instead:

claude
claude my-project

Troubleshooting

Typing claude does the same thing as before

Close and reopen your terminal. If that doesn't fix it, tell Claude "reload my shell config" and it will.

Not sure of your home folder's exact name or path

Ask Claude "what folders are at the top level of my user folder" and pick the one with work, personal, and learning inside it.

Never made a home folder in Week 1

Tell Claude that directly. It creates one now, at the top of your user folder, not the Desktop or Documents (those sync to iCloud automatically, which can corrupt a project stored inside them).
