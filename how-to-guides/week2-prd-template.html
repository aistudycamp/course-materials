Week 2 reference

A short PRD for your app

Answer these questions before Claude starts building.

Start with the user

Who is this for?Describe the person using the app and what they are trying to do.
What problem does it solve?Write the frustrating moment in one or two sentences.
What is the main flow?Write the path from opening the app to getting value.

Describe the first version

Core featuresList the three to five things the first version must do.
Data to saveWhat should still be there after the user refreshes the page?
Look and feelDescribe the mood, layout, colors, type, and one or two references.
Not in version oneName the tempting ideas to leave for later.

Give it to Claude

claude
Here is my product brief. Ask me one question at a time to clarify it. Then turn it into a short implementation plan with the pages, data, and first build slice. Do not write code until I approve the plan.

Keep the plan short enough to read. If Claude proposes too much, ask it to cut the first version down.
