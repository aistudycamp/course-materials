Week 2 reference

The terminal, without the fog

A small set of words and commands you will see while Claude builds your app.

The mental model
  • VS Code is the room.
  • The terminal is the conversation line into your computer.
  • Claude Code is the builder working through that line.
  • Your project folder is the boundary for the work.

Commands you may type

pwd

Show the folder you are currently in.

ls

Show the files and folders here.

cd folder-name

Move into a folder.

cd ..

Move up one folder.

code .

Open the current folder in VS Code.

npm install

Install the packages this project needs.

npm run dev

Start the local version of the app so you can open it in a browser.

What Claude can do

You can type the commands yourself, or ask Claude to run them:

claude
Check which folder we are in, open the project in VS Code, install what it needs, and start the app locally. Explain each step before you run it.

Keep the terminal visible while Claude works. If something feels unclear, ask: What did that command do?

One rule

Run commands from the project folder. If Claude says it cannot find a file or package, ask it to check the current path before changing anything.
