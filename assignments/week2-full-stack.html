Before you start

Open your workspace

  1. Open VS Code.
  2. Open the AI Study Camp folder you created in Week 1.
  3. Open a new VS Code terminal and start Claude Code there.
  4. Keep the project inside that folder tree. Do not start it from Desktop or Downloads.

If Claude Code is not installed yet, use the Claude Code setup guide before continuing.

Part 1 · Plan

Describe what you want to build

Build a to-do app, but make the experience yours. Decide who it is for, what makes it useful, and what it should feel like.

Tell Claude: I want to build a small to-do app. Before writing code, ask me questions one at a time about the user, the main flow, the visual direction, and the data we need to save. Then write a short PRD and implementation plan.

Stay in plan mode while you answer the questions. The plan is the bridge between your idea and the code.

Open the PRD template
Part 2 · Foundation

Set up the app and database

Ask Claude to create the app foundation and connect it to Supabase. You will use one Supabase project for the course, with this build's tables kept separate from later builds.

Tell Claude: Create the app foundation from the plan. Use Next.js for the app and my AISC Supabase project for the database. Before making changes, explain what you are about to create and ask me before anything destructive.

Use the Supabase guides when Claude needs to connect the project, create tables, or add authentication.

Part 3 · Build

Make it useful and make it yours

Work in small slices. After each slice, open the app in the browser and check what changed.

Core flow

Add, edit, complete, and delete a task. Make sure the data survives a refresh.

Accounts

Add sign up, sign in, and sign out. Each user should see only their own tasks.

Design

Choose the layout, type, colors, and small details. Ask Claude for options, then choose.

Check your work

Ask Claude to test the flow, inspect errors, and explain anything you do not understand.

Keep saying: Make one change, run the app, and show me how to check it in the browser.
Part 4 · Publish

Put it online

Commit your work, push it to GitHub, connect the repository to Vercel, add the Supabase environment values, and test the live URL.

Confirm the app works locally before deploying.
Ask Claude to commit and push the current working version.
Connect the GitHub repository to Vercel.
Add the same Supabase values to Vercel's environment variables.
Open the live app and test sign in, task changes, refresh, and sign out.
Deploy with VercelGit and GitHub reference
Finish

Bring it to the group session

Add the live link to your notes and be ready to show:

  • What problem your app solves.
  • The part you are most proud of.
  • One thing Claude got wrong or needed help with.
  • What you would build next.

The point is not a perfect app. The point is seeing how a coding agent can take an idea through planning, data, code, testing, and deployment.
