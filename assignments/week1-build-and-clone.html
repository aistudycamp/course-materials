Build and Clone

Goal. See how the same prompt produces different results depending on which model builds it and how hard that model thinks.

Two parts this week: build your own site three ways, then clone a real one.

Where do I do this?
All three builds happen in Claude Code inside the Claude desktop app. Use the Code tab, start a new session for each run, and point that session at the assignment folder. Do not use Claude Chat or Cowork for this assignment.
PART 1, BUILD YOUR OWN
1

The job

  • Pick something you want a website for. Your business, a hobby, an event, an idea you have been sitting on.
  • You will build the same site three times. Each run pairs a model with an effort level, so the two ends of the spectrum are obvious.

Why pair the fastest model with the least thinking, and the slowest with the most?
So the contrast is obvious. Haiku on low effort should feel quick and a little careless. Opus on max effort should feel slow and considered. That gap is the entire point of the exercise.

Why Auto, not Manual?
Manual stops and asks before every file it touches. For a one-shot build like this, that is a lot of clicking for no real decision on your end. Auto builds straight through.
Does the folder selection carry over to my next session?
No. Each new session starts pointed at nothing, or at whatever you last had open. Check the folder chip every time you start a fresh session in step 5.
4

The prompt

Click the highlighted part and type your idea. Leave the rest exactly as it is, every run.

Build me a complete one-page website for describe your website idea here.

Structure it like this: a hero section at the top with a big headline and one line under it, an about section, three sections showing what I do or offer, and a footer with contact details.

Put everything in one single HTML file I can open in my browser. Write real text that fits the subject, not placeholder text. Pick colors and fonts that fit the subject. Make it look good on a phone too.

When you are done, tell me in one sentence what you would improve next.
  • The structure lines are the scaffolding. Same skeleton every run is what makes the results comparable.
  • Hero, section, footer: the words designers use for the parts of a page. You will hear them all course.
Can I change the structure part too?
No, only your idea in the highlighted blank. If the structure changes between runs, you are no longer comparing the same thing.

Same three pairs as step 1: Haiku on low, Sonnet in the middle, Opus on max.

  • Fresh session for each run: new chat, re-select the folder, re-set both the model and the effort.
  • One shot each. No fixing, no follow-ups.

The slider does not show words like Low or Max, just dots. What do I do?
Drag to the far left for the Haiku run, roughly the middle for Sonnet, the far right for Opus. The exact label matters less than the position.
What if a model has no effort slider at all?
Some models fix their own effort and will not show the slider. If that happens, run it as is and note in step 6 that this model had no dial to move.
I forgot to reset something before sending. Do I start over?
Yes for that run. Close the chat without sending again, start a new one, and check the folder, model, and effort before you paste the prompt.
Claude says something about starting a local server, or a localhost address. What do I do?
Say no, or ask it to just save a single HTML file instead. You do not need a server for a one-page site, only a file you can double-click.
Can I skip opening the file and just grab a picture of it?
Yes. Ask Claude to save a screenshot of the finished site as a PNG in the same folder, named after the run. If it can, that PNG is what you bring Friday instead of opening the file live.
6

What to notice

  • Which run finished first, and was it worse for being fast?
  • Which wrote the most, and was more actually better?
  • Which looks best in the browser, before you knew which made it?
  • How did each one talk to you while it worked?
  • Haiku on low effort versus Opus on max: what did the extra thinking time actually buy?

Jot answers anywhere. Two sentences per question is plenty.

PART 2, CLONE SOMETHING REAL

Building from scratch shows you the differences between models. Cloning shows you the speed. Most people who see this done live do not believe it took ten minutes.

7

Pick a site and clone it

  • Pick something with a real design: your own site, your company's, or one you like the look of. One page is plenty, you do not need the whole site.
  • Same folder as before, week1-assignment, new session. Point the app at it the same way as step 3.

Take a screenshot of the page: press Cmd + Shift + 4, then drag over the part you want. It saves to your Desktop.

  • Send it and watch. This is not one shot: if something looks off, say so and let it fix it. A couple of rounds is normal.
  • Save it as clone-v1.html when you are happy with it.
Can Claude just visit the address itself instead of using a screenshot?
Some setups can. Try pasting the address in first. If nothing happens after a minute, fall back to the screenshot, that always works.
Is this allowed? It is someone else's design.
This stays in your own folder for practice. It is not for publishing as your own or presenting as a real product.
8

Make one or more real changes

Ask for one or more changes that are actually yours. Some ideas:

  • A different section
  • New colors
  • Different words
  • One added feature
  • Same session, same folder. Save the result as clone-v2.html, keeping v1 so you have a before and after.
  • This is the part that proves you can edit, not just copy.
