Piece 3 · Skills

Skills are the verbs Cacti knows

Each one is a repeatable workflow you taught it once.

/today  Morning brief

Pulls my whole day together (we'll see this live)

/visualize  Make a deck or diagram

Turns any doc into slides or a flowchart — this deck was built with it

/process-meeting  Transcript → notes

Drop a Zoom recording → clean summary + action items, filed

/quick-task  Capture in plain English

"Remind me to…" → routed to the right project automatically

40+ skills today — but it started with one. One good skill beats ten half-built ones.
