We're building a real-time Shoutout Wall — anyone can post a message of appreciation for a classmate and everyone sees it live. Stack: Next.js + InstantDB. This is the whole project — run everything from this folder.

4. Write these rules into CLAUDE.md:
   - Stack: Next.js + InstantDB. Run everything from this project folder.
   - Use InstantDB for ALL data and real-time — no other backend.
   - All shoutout data lives in InstantDB, not local React state.
   - No login required — anyone can post and clap.
   - Always TypeScript. Style with Tailwind.

Then build all four features in one pass. Do not stop between features, do not ask me to confirm each one, and do not use plan mode. Make a git commit after each feature so we can roll back, then keep going without waiting.

Feature 1 — Posting form
A form at the top of the page with three inputs: "Your name", "Who you're appreciating", and a message textarea. On submit, save a new shoutout to InstantDB with fields: fromName, toName, message, claps (default 0), and createdAt (timestamp). Use Instant's `transact` API. Clear the form after a successful post.

Feature 2 — Real-time feed
Below the form, render all shoutouts as a list of cards using Instant's `useQuery` hook so it updates live. Each card shows: who's appreciating who, the message, how long ago it was posted (e.g. "2m ago"), and the clap count. Style it cleanly with Tailwind. Test by opening the URL in two browser tabs — a post in one appears in the other with no refresh.

Feature 3 — Clap counter
Add a 👏 button on each card. Clicking it increments that shoutout's `claps` using `transact` with the existing ID. InstantDB handles the optimistic update automatically — no extra local state. The count should persist after a page refresh.

Feature 4 — Sort by most clapped
Sort the feed so the post with the most claps is at the top. Newer posts break ties.

Bonus (only if time) — Confetti on clap
When someone claps, fire confetti from the button using the `canvas-confetti` npm package.

Build all of it now. Tell me the URL when it is ready to test.
