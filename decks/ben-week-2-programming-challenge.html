We're building a real-time Shoutout Wall. Anyone can post a message of appreciation for a classmate and everyone sees it live. Stack: Next.js + InstantDB + Tailwind.

The starter is already running: sign in works, the schema is pushed, the dev server is up.

Build all four features in one pass. Do not stop between features, do not ask me to confirm each one, and do not use plan mode. Make a git commit after each feature so we can roll back, then keep going without waiting.

Feature 1: Posting form
A form at the top with three inputs: your name, who you're appreciating, and a message. On submit, save a shoutout to InstantDB using Instant's `transact` API, with claps starting at 0 and createdAt as a timestamp. Clear the form after posting.

Feature 2: Real-time feed
Below the form, render all shoutouts as cards using Instant's `useQuery` hook so it updates live. Each card shows who is appreciating who, the message, how long ago it posted, and the clap count. Test by opening two browser tabs.

Feature 3: Clap counter
A clap button on each card that increments that shoutout's claps using `transact` with the existing ID. The count persists after a refresh.

Feature 4: Sort by most clapped
Most clapped at the top. Newer posts break ties.

Bonus, only if time: give it personality
Restyle the wall so it does not look like the default. Pick a palette and commit to it. Fire confetti on a clap using `canvas-confetti`.

Build all of it now. Tell me the URL when it is ready to test.
