Moving around a terminal.

A terminal always sits inside one folder. Four commands are the whole skill.

pwd ls cd folder-name cd ..
VS Code's integrated terminal already starts inside whatever folder you opened. That's one reason we teach it.
# where am I
$ pwd
/Users/maria/Desktop

# what's here
$ ls
notes.txt   old-project

# step into a folder
$ cd old-project
$ pwd
/Users/maria/Desktop/old-project

# step back out
$ cd ..
pwd tells you where you are right now. ls lists what is inside the current folder. cd folder-name steps into a folder that ls just showed you. cd dot dot steps back out one level. VS Code's integrated terminal already starts inside whatever folder you opened in the file tree, so most of this course you will open the right folder in VS Code first and never need cd at all. It matters for the raw terminal and for finding your way if you ever land somewhere unexpected.

Worth saying once if anyone asks why the prompt calls out "the real claude binary": a shell function named claude shadows the real program, so if its body just calls claude again it recurses into itself and never reaches Claude Code.
