Pair Programming Challenge

Re-create ChatGPT.

Build a streaming chat app with a unique personality and knowledge of our curriculum, in one prompt.

The whole point

One file. Infinite personalities.

The system prompt is the soul of your assistant. Change one file, and everything changes: the voice, the vibe, even the design.

Setup

Paste this into Claude.
You're done.

Works with the Claude Code desktop app or the CLI. The API key is pinned in the class chat. Drop it in where you see [KEY].

Set up a Chat Assistant app on my Desktop:

1. Clone https://github.com/tiobenito/ChatAssistantPairProgramming.git into ~/Desktop as chat-asst
2. cd into it, run npm install
3. cp .env.local.example .env.local
4. Set OPENAI_API_KEY in .env.local to: [KEY, from class chat]
5. Wire up the Responses API with streaming so responses appear word-by-word
6. Render assistant output as markdown
7. Give the assistant a Shakespeare persona, unmistakably Elizabethan from the first word
8. Start npm run dev as a background process
9. Tell me when localhost:3000 is up and show me how to change the persona

Build all of this in one pass. Don't stop between steps to ask me, and don't use plan mode.

Now play with it.

Edit lib/system-prompt.ts and tell Claude what to change. Refresh. New assistant.
