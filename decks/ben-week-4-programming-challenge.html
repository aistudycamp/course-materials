Concept deep-dive

Sending Ref Files to LLM API.

Example: sending the Vibe Coding Foundations curriculum via OpenAI API when a user asks about the course.

Approach 01
Send docs + System Prompt each time ($$)
Simplest to implement, but uses unnecessary tokens and increases costs.
Approach 02 · recommended
Keyword Detection
Check the user's message for specific course-related keywords and include the curriculum only when a match is found. Fast, cheap, and simple — but may miss edge cases.
Approach 03
AI Classification
First ask the AI whether the user's message is about the course, then include the curriculum only if it says yes. More accurate, but adds an extra API call — more latency and cost.
Approach 04
Tool / Function Calling
Expose a get_curriculum tool and let the AI call it only when it decides it needs the curriculum. More autonomy, but more complexity and slower responses (back-and-forth).
