Your starting prompt

Paste this into Claude.

We're building a real-time collaborative whiteboard. Stack: Next.js + InstantDB. The Next.js app lives in the `app/` subfolder of this repo.

Before writing any code, do these three things in order:

1. Update InstantDB to the latest version — run this from the `app/` folder:
   npm install @instantdb/react@latest @instantdb/admin@latest @instantdb/core@latest

2. Start the dev server in the background — run `npm run dev` from the `app/` folder.
   Tell me the localhost URL when it's running.

3. Write these rules into CLAUDE.md at the repo root:
   - Stack: Next.js + InstantDB. The Next.js app is in the `app/` subfolder.
   - Use InstantDB for ALL data, auth, and real-time — no other backend.
   - Magic Link auth only — no passwords, no OAuth.
   - All board state lives in InstantDB, not local React state.
   - One shared room called 'main-board'.
   - Always TypeScript.

Then build these features in order. Use plan mode (Shift+Tab) before writing code for each one. Stop after each feature and wait for me to confirm it works before moving on.

Feature 1 — Magic Link auth
A login screen with an email input. Once the user clicks the magic link in their email, land on a board page showing their email and a sign-out button.

Feature 2 — Real-time sticky notes
Users can add sticky notes with text to the shared board. Notes must persist in InstantDB and sync live for everyone connected — test by opening two browser tabs.

Feature 3 — Live cursors + presence
Track each user's mouse position using InstantDB rooms, labeled with their email. Use board-relative coordinates from the board div's bounding rect — not clientX/clientY directly — so cursors don't drift when the board scrolls.

Feature 4 — Permissions
Any authenticated user can create, read, update, move, and delete any item on the board. Unauthenticated users cannot access the board at all.

Start with Feature 1 now.
